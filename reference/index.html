    API reference¶

    The MCP tool surface is a thin wrapper over these modules. Most consumers should use the tools described in the overview; this reference is for authors embedding the registry directly in a Python service.

    accept_a_single_root_as_a_string classmethod ¶

    accept_a_single_root_as_a_string(value: object) -> object

    Keep every configuration written before this field took a list.

    One directory was the only option for long enough that config files in the wild spell it as a string, and rewriting them is not something a release should require.

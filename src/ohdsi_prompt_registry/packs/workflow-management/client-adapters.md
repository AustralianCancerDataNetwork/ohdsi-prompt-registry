# Reuse elicitation transport guidance

Workflow management does not define native question payloads. Load the `user-elicitation` core when collecting information. If the transport is unclear, read that pack's declared `client_adapters` document explicitly.

The workflow must retain the request-to-decision association while the adapter collects the answer. A returned question-tool call is not a resolved prerequisite. Apply domain checks and the workflow's actual requirements before progression.

For batch execution, retain unresolved requests in the handoff. For an external coding agent, report observed adherence rather than claim runtime enforcement.
